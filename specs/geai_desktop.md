# GEAI Desktop

## Mission

GEAI Desktop is the intelligence layer above the operating system.

The user should accomplish goals instead of managing applications.

---

## Version 1 Goal

Become the first application a user opens after turning on their computer.

---

## Core Features

- Resume Workspace
- Natural Language Interface
- Project Awareness
- File Understanding
- Automation
- Local AI
- Offline First

---

## User Interface

GEAI opens directly into a chat interface.

The user never sees commands.

Examples:

Continue my work

Find my invoice

Build a portfolio website

Organize Downloads

Research this idea

## Success Metric

A user should complete everyday work without manually opening folders or remembering where information is stored.
