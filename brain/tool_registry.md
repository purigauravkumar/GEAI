# GEAI Tool Registry

## Purpose

Every capability in GEAI is a Tool.

The Brain never performs work itself.

The Brain selects one or more Tools to accomplish a user's goal.

# Brain Rules

The Brain NEVER

- Reads files directly

- Writes code directly

- Browses internet directly

- Runs automation directly

The Brain ONLY

- Understands intent

- Chooses Tools

- Creates plans

- Evaluates results

- Stores memory
