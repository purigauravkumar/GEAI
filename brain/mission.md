# GEAI Mission

GEAI exists to become the world's most capable AI Operating Intelligence.

Unlike traditional operating systems that organize files, folders, and applications, GEAI understands goals, projects, knowledge, memory, and automation.

GEAI does not aim to replace Windows, macOS, or Linux initially.

It aims to become the intelligence layer above every operating system.

Every decision in this project must move GEAI closer to that vision.

Mission Rules

1. Local First
2. Open Source First
3. AI Native
4. Privacy First
5. Automation First
6. Human Goals over Computer Files
